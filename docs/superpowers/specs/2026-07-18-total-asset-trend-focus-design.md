# 总资产走势聚焦设计

## 背景

总览页的“总资产走势”当前同时绘制总资产、投资类和余额类三条折线。纵轴包含数值较低的分类资产并从零附近展开，导致总资产折线被压缩在较窄的垂直区域，细微波动不容易辨认。

用户只需要在这张图中观察总资产，不需要按资产类型筛选，也不需要同时比较投资类和余额类。

## 目标

1. 总资产走势图只展示总资产折线。
2. 纵轴围绕当前可见总资产数据自动缩放，让波动更清晰。
3. 保留现有 `日 / 周 / 月 / 季 / 年` 时间尺度切换。
4. Tooltip 只展示周期、实际快照时间和总资产。
5. 不改变快照、资产、汇率或趋势聚合的数据结构。

## 非目标

1. 不增加资产类型筛选控件。
2. 不改变总览页顶部的投资类、余额类等统计指标。
3. 不改变收入走势图。
4. 不改变微信小程序。
5. 不增加后端接口或持久化配置。

## 交互设计

“总资产走势”继续显示现有时间尺度控件。图表区域只保留一条名为“总资产”的蓝色折线，移除“投资类”和“余额类”折线。

纵轴根据当前尺度下的总资产点计算显示范围：

- 有多个不同数值时，以最小值和最大值为基础，在上下各留出数据跨度 10% 的边距；边距至少为 1 元。
- 所有点相同时，使用一个与当前金额规模相称的最小边距，避免纵轴范围退化为零宽度。
- 纵轴下界不得小于零。
- 金额刻度继续使用现有的“万”格式。

切换日、周、月、季、年时，纵轴随新的可见数据重新计算，不发起新的网络请求。

Tooltip 继续显示：

```text
周期：2026-07-18
实际快照：2026-07-18 10:30
总资产：449,123.45
```

## 技术设计

### 纵轴范围

在 `domain/snapshots.ts` 新增一个纯函数，输入当前 `TotalAssetPoint[]`，输出 Recharts 可直接使用的 `[min, max]` 数值范围，使边界计算可以脱离 React 独立测试。

函数遵循以下规则：

1. 忽略非有限数值。
2. 无有效数据时返回安全的默认范围。
3. 不同数值使用 `max(数据跨度 × 10%, 1 元)` 作为上下边距。
4. 相同数值使用 `max(金额绝对值 × 5%, 1 元)` 作为上下边距。
5. 最终下界使用 `max(0, 最小值 - 边距)`，上界使用 `最大值 + 边距`。
6. 无有效数据时返回 `[0, 1]`。

### 页面组件

`DashboardPage` 使用当前 `assetChartData` 计算纵轴范围，并将结果传给资产走势图的 `YAxis domain`。

从资产走势图中删除：

- `investmentAmount` 折线；
- `balanceAmount` 折线。

保留 `TotalAssetPoint` 中现有字段，避免为了展示层变化破坏已有领域接口或其他调用点。

现有通用 `TrendTooltip` 由 Recharts 的实际 payload 决定展示行。删除两条折线后，Tooltip 会自然只收到总资产项，不需要引入额外状态。

## 数据流

```text
已有快照、快照值、资产、汇率
  -> buildScaledTotalAssetSeries
  -> 当前尺度的 TotalAssetPoint[]
  -> 计算总资产纵轴范围
  -> 单一总资产折线
```

## 异常与边界情况

- 没有趋势点：继续沿用现有行为，不显示走势图。
- 只有一个趋势点：生成非零纵轴范围，并正常显示该点。
- 所有总资产值相同：生成非零纵轴范围，折线位于图表中部。
- 总资产接近零：纵轴下界收敛到零，不显示负金额刻度。
- 无效金额：范围计算忽略该点，不让图表崩溃。

## 测试策略

领域测试覆盖：

1. 多个总资产值生成围绕数据的非零范围，而不是从零开始。
2. 相同总资产值仍生成有效范围。
3. 接近零的数据不会产生负下界。
4. 空数据和无效数值返回安全范围。

页面测试覆盖：

1. 资产走势图只渲染 `totalAmount` 折线。
2. 不再渲染 `investmentAmount` 和 `balanceAmount` 折线。
3. `YAxis` 收到根据当前总资产数据计算的范围。
4. 日、周、月、季、年控件仍然可用，切换时不重新请求 API。
5. 收入走势图保持不变。

## 验收标准

1. “总资产走势”只显示一条总资产折线。
2. 当前数据的最低点和最高点在纵轴中占据明显的垂直空间，波动比原图更易辨认。
3. 纵轴不出现负金额刻度。
4. 时间尺度切换行为与现状一致。
5. Tooltip 只包含总资产，不包含投资类或余额类。
6. 总览页其他统计和收入走势图不受影响。
