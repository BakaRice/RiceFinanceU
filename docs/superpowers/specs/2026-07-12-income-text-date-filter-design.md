# 收入文字日期与顶部筛选设计

## 日期输入

收入表的发生日期改为普通文本单元格，接受 `2026-07-10`、`2026/7/10`、`20260710` 和 `2026年7月10日`。有效输入在失焦时统一规范为 `YYYY-MM-DD`；无效日期保留原文字、标记错误并阻止统一保存。

## 顶部筛选

表格工具栏下方增加一行筛选：开始日期、结束日期、分类、来源关键词和清除筛选。日期筛选使用相同的宽松文字规则；无效筛选条件标红但不参与过滤。筛选只改变显示行，不改变草稿、待删除集合、dirty 计数或保存内容。

## 验证

- 领域测试覆盖四种日期格式、闰年和非法日期。
- 页面测试覆盖失焦规范化、非法日期阻止保存、组合筛选和清除筛选。
- 本地真实数据验证键盘输入、筛选结果、深色主题和无误保存风险。
