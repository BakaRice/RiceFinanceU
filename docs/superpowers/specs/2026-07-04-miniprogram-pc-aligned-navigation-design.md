# 小程序 PC 同构导航设计

## 背景

小程序不是 RiceFinanceU 的另一套产品，而是同一产品的移动端适配。产品心智应与 PC 端保持一致：用户在任何端看到的核心入口、页面命名和操作层级都应相同；只有在移动端布局受限时，才调整呈现方式。

## 信息架构

PC 端侧边栏为：

- 总览
- 资产管理
- 快照录入
- 数据管理
- 退出

小程序底部 Tab 对齐为：

- 总览
- 资产
- 录入
- 数据

`退出` 不作为 Tab。它属于账号动作，放在 `数据` 页底部。`刷新` 不作为常驻主按钮，改为进入页面自动加载、下拉刷新、失败时重试。

## 页面职责

`总览` 展示总资产、投资/余额/收益、资产表和快照历史。它不承载“录入”“退出”“刷新”等常驻主按钮。

`资产` 对应 PC 的资产管理。现阶段实现资产列表、新增资产、编辑资产、停用资产。移动端用列表和表单抽屉式布局替代表格。

`录入` 对应 PC 的快照录入。它保留日期、时间、资产金额、收益、收益率、备注和保存动作。

`数据` 对应 PC 的数据管理。移动端不使用文件选择控件，改为导出 JSON 到剪贴板、从文本框粘贴 JSON 导入；功能语义与 PC 的导入/导出一致。

## 登录与导航

登录页保持为非 Tab 页面。登录成功后使用 `switchTab` 进入 `总览`。未登录访问任意业务 Tab 时跳回登录页。

## 验证

用小程序配置测试锁定四个 Tab 顺序；用 API 测试锁定资产管理和数据管理接口；用页面测试锁定登录后跳转方式和总览无常驻主操作按钮。
