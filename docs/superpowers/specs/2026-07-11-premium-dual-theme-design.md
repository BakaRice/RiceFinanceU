# 高级中性双主题设计

日期：2026-07-11

## 背景

鲜明高密度工作台已经建立了更紧凑的布局和总览信息关系，但第一版色彩由紫色承担了品牌、导航、按钮、摘要和图表等过多职责，容易呈现常见 SaaS 或 Web3 模板感。用户希望保留现代感和少量炫彩，同时追求更接近高端消费电子产品的克制质感，并同时支持浅色与深色模式。

## 已确认决策

- 支持 `浅色`、`深色`、`跟随系统` 三种主题偏好。
- 用户选择持久化到浏览器，本地长期生效。
- `跟随系统` 在系统主题变化时即时更新。
- 页面首次渲染前解析主题，避免先亮后暗的闪烁。
- 浅色和深色共享相同信息架构、密度、组件和状态语义。
- 后端接口、领域模型和数据存储不变。

## 视觉方向

高级感来自中性底色、精确对比、细边框、稳定数字和少量高纯度数据色，而不是大面积紫色或霓虹光效。

### 浅色主题

- 画布使用珍珠白与极浅冷灰，而不是淡紫色。
- 数据表面使用干净白色。
- 正文使用石墨黑，次级信息使用中性灰。
- 主操作使用清澈钴蓝。
- 紫色只允许作为收入等特定数据系列色，不再作为全局品牌主色。
- 摘要带可以有非常轻的冷灰蓝层次，但不出现明显紫色底。

### 深色主题

- 画布使用接近 OLED 黑的中性黑，不偏紫。
- 数据表面使用黑灰层次，面板之间依靠亮度差和细边框区分。
- 主数字使用高亮白色，正文和辅助信息使用银灰梯度。
- 主操作使用清澈冰川蓝。
- 图表允许蓝、青、绿、琥珀、洋红等光谱色，但不添加大范围外发光。
- 阴影只用于浮层，普通面板不做玻璃拟态。

### 光谱色规则

- 总资产：钴蓝/冰川蓝。
- 投资类：青色。
- 余额类：琥珀色。
- 收入：低占比紫色，仅用于收入数据语义。
- 正收益：翡翠绿。
- 负收益：珊瑚红。
- 受限收入：洋红。
- 光谱渐变只用于品牌标记和极细强调线，不用于大面积卡片背景。

## 主题状态模型

主题偏好类型：

```ts
type ThemePreference = 'light' | 'dark' | 'system'
type ResolvedTheme = 'light' | 'dark'
```

浏览器存储键固定为 `ricefinanceu-theme`。

解析规则：

1. 存储值为 `light` 或 `dark` 时直接使用。
2. 存储值为 `system` 或不存在时读取 `prefers-color-scheme: dark`。
3. 非法存储值回退为 `system`。
4. 将解析结果写入根元素 `data-theme="light|dark"`。
5. 将偏好写入根元素 `data-theme-preference="light|dark|system"`，便于测试和诊断。

## 主题选择器

- 在主应用左侧栏底部、账户区上方提供三档选择器。
- 选项为 `自动`、`浅色`、`深色`，分别对应 `system`、`light`、`dark`。
- 使用紧凑分段按钮，当前偏好拥有明确的 `aria-pressed` 状态。
- 登录页右上角也提供同一选择器，使未登录用户可以切换主题。
- 选择器仅改变浏览器视觉状态，不调用 API。

## CSS 架构

- `:root` 保存共享尺寸与浅色默认变量。
- `:root[data-theme='light']` 定义浅色语义变量。
- `:root[data-theme='dark']` 覆盖相同变量名，不让业务组件判断主题。
- 面板、按钮、输入、表格、导航、反馈、图表统一消费语义变量。
- 清理直接写在页面 CSS 中的浅色背景和紫色主色，改为主题变量。
- Recharts 的颜色使用 CSS 变量字符串，使主题切换后自动更新。

## 主题切换行为

- 手动切换立即更新，不刷新页面。
- 选择 `跟随系统` 后注册系统主题监听。
- 切换到手动模式后，系统变化不覆盖用户选择。
- 组件卸载时移除监听。
- `localStorage` 或 `matchMedia` 不可用时安全回退到浅色，不阻止应用启动。

## 可访问性

- 三个主题按钮具有清晰的可访问名称和按下状态。
- 深色主题下文本、边框、输入和焦点环保持足够对比度。
- 正负状态仍保留正负号和文字，不只依赖颜色。
- 主题切换不改变 DOM 阅读顺序或键盘导航。

## 测试与验收

- 纯函数测试覆盖合法偏好、非法值、系统深浅解析和持久化。
- 组件测试覆盖三档选择、`aria-pressed` 和根元素属性更新。
- 应用壳测试验证登录页与主应用都能访问主题选择器。
- 完整前端、Worker、小程序测试与生产构建通过。
- 本地浏览器分别检查浅色、深色和跟随系统状态。
- 两个主题下总览、资产、收入、定投、快照录入和数据管理均可读且无横向溢出。

## 完成标准

1. 紫色不再主导全站品牌和控件。
2. 浅色模式呈现珍珠白、石墨黑和清澈蓝的中性高级感。
3. 深色模式呈现中性 OLED 黑与银灰层次，不偏紫、不霓虹化。
4. 三档主题可切换、可持久化、可跟随系统且无明显首次闪烁。
5. 现有高密度布局和总览双栏关系保持不变。
6. 没有后端、API 或领域模型改动。
