# 大盘只读双趋势设计

## 目标

大盘只回答“我的资产和收入发生了什么”，不承担收入写入。总资产走势与收入走势并排展示，提高信息密度，同时保持资产存量与收入流量各自独立。

## 布局

- 桌面端使用一行两列的趋势区：左侧总资产走势，右侧收入走势。
- 两张图等高，各自拥有标题、坐标轴、Tooltip 和尺度控制。
- 总资产图只展示总资产、投资类、余额类。
- 收入图只展示聚合收入，默认按月，并支持日、周、月、季、年。
- 1100px 以下改为上下排列，避免图表过窄。

## 只读边界

- 删除大盘中的“记录收入”“编辑最近一笔”“删除收入”以及收入编辑弹窗。
- 收入摘要继续展示最近月可支配、总流入、受限流入及分类金额。
- 收入区只保留“查看收入明细”链接，跳转 `/income` 完成新增、修改和删除。
- 不修改收入 API、收入事件模型或资产快照模型。

## 验证

- 页面测试确认双图位于同一个趋势行，且资产图不包含收入线。
- 页面测试确认大盘没有收入写入按钮或弹窗，只有 `/income` 链接。
- 领域测试覆盖收入日、周、月、季、年聚合。
- 本地真实数据验证桌面双列、窄屏堆叠和深色主题。
