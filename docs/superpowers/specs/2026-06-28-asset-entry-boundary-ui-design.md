# 资产管理与快照录入边界优化设计

日期：2026-06-28

## 背景

RiceFinanceU 当前是一个本地单人使用的资产快照账本。系统已经采用“资产项 + 快照”的模型：

- 资产项表示长期存在、可被持续追踪的账户或标的。
- 快照表示某个时间点的资产状态录入。
- 快照值表示某个资产在某次快照里的金额、收益和收益率。

现有录入页支持在填写快照时内联新增资产项。这让首次录入更方便，但也让“资产主数据维护”和“快照盘点录入”的边界变弱。用户反馈认为这会让产品职责不够清晰。

本次设计目标是保留系统简单性，同时让 UI/UX 更像成熟的管理系统：资产管理负责主数据，快照录入负责引用已有资产生成一张有明确时间归属的盘点单。

## 产品类比

采用 PMS / OMS 类比来定义边界：

- PMS 或商品系统维护商品主数据。
- OMS 或订单系统创建订单时引用商品，但不负责维护商品主数据。

对应到 RiceFinanceU：

- 资产管理是 PMS，维护资产主数据。
- 快照录入是 OMS 或盘点单，引用资产并记录本次金额状态。
- 如果录入时发现缺少资产，录入页可以提供快速跳转到资产管理的入口，但不在录入流程内直接创建资产。

## 产品目标

1. 明确资产管理与快照录入的职责边界。
2. 移除录入页内联新增资产项能力。
3. 保留从录入页快速跳转到资产管理的入口。
4. 提升录入页成熟度，包括数值格式、录入效率、未保存保护、保存前复核。
5. 保持系统简单，不引入复杂工作流、权限、审批或多用户协作。

## 非目标

- 不合并资产管理和快照录入为一个工作台。
- 不引入交易流水模型。
- 不新增商品、订单、PMS、OMS 等真实领域实体。
- 不做联网行情拉取。
- 不引入复杂设置系统。本次可以为后续“数据管理/设置”预留方向，但不是必须一次完成。

## 信息架构

建议将导航命名调整为：

- `总览`
- `资产管理`
- `快照录入`

`资产管理` 表示主数据维护页。

`快照录入` 表示创建新的资产快照，类似填写一张盘点单。

备份导入导出不应长期放在快照录入页，因为它属于数据管理能力，会稀释录入页职责。若本次实现范围允许，可以新增 `数据管理` 入口；若希望控制范围，可以先保留但在实现计划中作为后续任务。

## 页面职责

### 资产管理页

资产管理页负责维护资产主数据：

- 名称。
- 类型。
- 币种。
- 平台或机构。
- 备注。
- 启用或停用状态。

资产管理页可以展示最新金额、收益和收益率，但这些字段必须是只读参考，不能让用户误以为可以在这里修改金额。

新增资产后，页面可以提示用户：

> 资产已新增。现在可以去快照录入为它填写金额。

### 快照录入页

快照录入页负责创建一次新快照：

- 选择快照日期和时间。
- 填写备注。
- 从已有启用资产中选择本次要更新的资产。
- 填写金额。
- 对投资类资产填写收益和收益率。
- 保存快照。

快照录入页不再内联新增资产项。

当没有资产或找不到目标资产时，提供明确入口：

> 缺少资产项？去资产管理新增

如果用户已有未保存录入内容，点击跳转到资产管理前需要确认，避免丢失本次输入。

## 录入体验规则

快照录入应像填写一张盘点单：

1. 顶部展示当前正在录入的快照时间。
2. 日期、时间、备注放在表单顶部。
3. 输入金额时自动勾选该资产。
4. 已勾选或已修改资产应比未更新资产更醒目。
5. 未勾选资产沿用上次快照值。
6. 保存按钮应易于触达，尽量避免用户必须滚到页面底部才可以保存。
7. 页面应实时显示本次已更新资产数量。
8. 保存后刷新最新快照状态，并清空本次备注和修改状态。

## 数值与格式规则

### 金额

- 输入允许最多 2 位小数。
- 展示使用千分位和 2 位小数，例如 `¥12,345.67`。
- 金额不能为负数。
- 空值展示为 `-`，不要把未知值显示成 `0`。

### 收益

- 投资类资产支持收益和收益率。
- 收益输入允许负数，最多 2 位小数。
- 收益展示保留 2 位小数。
- 正收益使用绿色，负收益使用红色，零值使用中性色。

### 收益率

- 输入单位为百分比，例如用户输入 `8.65` 表示 `8.65%`。
- 存储继续使用小数，例如 `0.0865`。
- 展示保留 2 位小数，例如 `8.65%`。
- 收益率不能小于 `-100%`。

### 多币种

- 明确显示资产币种，例如 `CNY`、`USD`、`HKD`。
- 金额符号可以保留，但不能替代币种标识。
- 汇总折合 CNY 的计算逻辑保持现状。

## 防错规则

### 未保存跳转保护

快照录入页存在以下任一情况时，视为有未保存内容：

- 用户修改了日期、时间或备注。
- 用户勾选或取消勾选资产。
- 用户修改了金额、收益或收益率。

此时点击跳转到资产管理，应弹出确认：

> 当前快照尚未保存，离开后本次填写内容会丢失。确定要离开吗？

### 保存前复核

保存前应进行轻量复核，不需要复杂审批。复核内容包括：

- 快照时间。
- 本次更新资产数量。
- 与上次金额相比变化较大的资产。

建议规则：如果某个资产本次金额相对上次金额变化超过 50%，在复核中突出显示。没有上次金额的新资产不做异常提示。

### 资产停用

资产停用仍保留历史快照引用。资产管理页停用时继续提示：

> 停用后不会出现在新的快照录入中，但历史快照仍会保留。

## 推荐实现范围

第一批实现应聚焦在最能提升清晰度和信任感的部分：

1. 导航和页面标题重命名。
2. 移除快照录入页的内联新增资产项。
3. 增加从快照录入到资产管理的快速跳转。
4. 有未保存录入内容时跳转前确认。
5. 统一金额、收益、收益率输入与展示规则。
6. 增加录入摘要和保存前轻量复核。

第二批可以考虑：

1. 将备份导入导出移到数据管理页。
2. 增加资产搜索和筛选。
3. 增加保存按钮固定区域。
4. 增加更精细的移动端录入优化。

## 验收标准

1. 快照录入页不再能直接创建资产。
2. 快照录入页提供清晰的资产管理跳转入口。
3. 用户有未保存录入内容时，跳转到资产管理会收到确认提示。
4. 资产管理页仍能新增、编辑、停用资产。
5. 新增资产后，用户可以回到快照录入页为它填写金额。
6. 金额和收益展示保留 2 位小数并使用千分位。
7. 收益率展示保留 2 位小数百分比。
8. 空值显示为 `-`。
9. 保存快照前能看到本次更新数量和快照时间。
10. 现有测试通过，新增行为有测试覆盖。
