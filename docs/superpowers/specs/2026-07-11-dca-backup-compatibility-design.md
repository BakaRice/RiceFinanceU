# 定投备份兼容设计

## 目标

让定投计划作为 `Asset.dcaPlan` 随完整账本可靠导出和恢复，并消除导入过程中静默丢弃定投数据的情况。

## 兼容规则

- 继续支持 schema v1 和 v2；旧备份缺少 `dcaPlan` 时按“无定投计划”导入。
- 合法定投计划仍允许数字字符串、备注前后空格等可安全规范化的输入。
- 定投只允许出现在基金、股票和黄金资产上。
- 备份一旦显式包含 `dcaPlan`，它必须是启用的有效计划，并包含受支持的频率和大于零的每期投入金额。
- 非法定投导致整次导入失败；系统不得删除定投后继续报告成功。
- 可选字段无效时同样拒绝导入，避免目标金额、目标日期、偏离容忍度等内容被静默裁剪。

## 前端体验

- 导入确认页显示定投计划数量。
- 前端预检逐个校验资产上的 `dcaPlan`，错误信息包含资产位置或名称以及具体原因。
- 存在定投错误时仍可查看预检结果，但确认导入按钮不可用。
- 数据管理页说明完整备份包含定投计划。

## 后端守门

- Worker 在写入 KV 前执行严格定投校验。
- 任意定投错误返回 HTTP 400，并指出 `assets[index].dcaPlan` 及原因。
- 只有完整备份全部通过校验后才整体替换 KV 数据。

## 测试

- 合法定投导入导出往返保持不变。
- 无 `dcaPlan` 的旧备份继续成功。
- 非投资资产携带定投、无效频率、非正数投入和无效可选字段均拒绝导入。
- 前端预检统计合法定投，并把上述问题标为严重问题。
- 页面显示定投数量和更新后的备份说明。
