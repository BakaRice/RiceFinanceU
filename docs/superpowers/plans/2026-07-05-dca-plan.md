# DCA Plan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add lightweight DCA plan persistence, export, and target-period contribution estimates for investment assets.

**Architecture:** `Asset.dcaPlan` stays in asset master data and never participates in valuation or snapshot completion. Pure DCA helpers sanitize plans and estimate contribution gaps; Worker mirrors the persistence sanitizing; React pages edit and display the plan.

**Tech Stack:** TypeScript, React, Vitest, Node test runner, Cloudflare Worker JavaScript.
